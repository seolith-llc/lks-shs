# Prototypes

Track decided: **application track first** — a small web service inside a healing loop: health probes, restart/rollback, canary, AI triage agent.

Each prototype must be:
1. Runnable with one command (documented in its README)
2. Equipped with failure injection — no demo without a wound to heal
3. Annotated with links to the decision record explaining why this design over the alternatives (`docs/architecture/decisions/`)
