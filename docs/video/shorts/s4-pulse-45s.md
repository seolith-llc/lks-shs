# Short S4 · PULSE in 45 seconds

## How self-healing software works
- 70 years of one idea
- the same loop at every layer
- from ECC memory to AI agents

Every self-healing system ever built, from server memory to AI ops agents, runs the same five steps. Seventy years of engineering, one loop. It is called PULSE.

## The loop
- **P**erceive — sense the signals
- **U**nderstand — classify the failure
- **L**ocalize — find the exact component
- **S**olve — restart, rollback, patch
- **E**volve — verify, learn, harden

Perceive. Understand. Localize. Solve. Evolve. The heartbeat exists at every layer of the stack. Liveness probes. Watchdogs. Consensus heartbeats. Dead man's switches.

## The one rule
-! 1 rule | nothing is healed until a non-AI oracle says so

And one rule above all: nothing counts as healed until something that is not the healer says so. Tests. Metrics. A golden request. A fix that is not verified is a guess. There is a runnable prototype in the repo on screen. Go break it.
