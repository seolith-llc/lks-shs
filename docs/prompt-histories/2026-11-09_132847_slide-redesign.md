# Request

# Response

Voice approved (edge-tts stays). Slides rebuilt from scratch — and the investigation found they weren't just plain, they were **broken**:

**Root cause discovered via marker-rect pixel probes:** `qlmanage` renders non-square SVGs at ~1.66× scale, top-left anchored — every slide in prior renders was shifted and clipped at the right/bottom. The earlier corner-pixel check passed because the uniform navy background hid the damage (weak-oracle lesson recorded). The first diagnosis ("letterboxing") was wrong; both the repo memory and this history now record the corrected fact.

**Fix (Decision 007):**
1. **Rasterization rule:** slides authored on a 1280×1280 **square** canvas (16:9 band centered), rasterized `-s 2560` (2× supersample), ffmpeg `crop=2560:1440,scale=1280:720`. Square SVGs map 1:1 — probe-verified.
2. **Design system v3:** navy gradient + grid + corner glows; LKS-SHS/EP badges; white titles + gold underline; bullet rows with colored icon chips (PULSE stage palette); **big-stat callout cards** (new `-! <BIG> | <label>` script syntax, display-only); segmented progress bars; dedicated centered title card (PULSE wordmark + five stage dots); vertical centering of content blocks.
3. Stat callouts added to the 10 number-heaviest slides across episodes 01–08.

**Acceptance gate (two rounds):** round 1 visual-judge on samples → FAIL (clipping, entities, imbalance — caught the mapping bug's symptoms) → fixed; round 2 → all PASS; round 3 on frames extracted from the **final MP4s** → PASS. Evidence frames committed to `docs/video/verification/`.

**Bugs fixed en route:** parser didn't recognize `-! ` stats (they leaked into narration, lengthening audio — caught by duration delta, fixed, durations now reproduce exactly); `render_all.sh` `set -e` aborted whole batch on one transient failure (now per-episode fault-tolerant).

All 8 episodes re-rendered; durations unchanged from the neural-voice pass (2:01–2:16), so post stamps remain valid. Memory updated: `lks-shs-av-quality-standard` (voice + slides + visual-judge gate) and corrected `lks-shs-machine-gotchas`.
